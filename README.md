# Юмани Терминал + Пульт

Экосистема: телефон-терминал (APK) + пульт на ПК (EXE).

## Возможности
- Подключение по 6-значному коду (UDP-маяк + автоскан сети как запасной путь).
- Оплата **улыбкой**: терминал открывает камеру, снимает покупателя, оплата проходит.
- Оплата **по QR**: на терминале генерируется QR со ссылкой `yumani://pay?...`.
- **Защита от случайного выхода**: при оплате APK просит разрешение "поверх окон"
  и держит зелёную плашку "идёт оплата — не выходите с экрана".
- Звуки: джингл на запуск, "дзынь" на успех, мягкий сигнал на отказ, тик на нажатия.

## Сборка (всё делает GitHub)
После пуша во вкладке Actions появятся два workflow:
- **Build APK** -> артефакт `app-debug-apk` (ставится на телефон).
- **Build EXE + Installer** -> артефакты `TerminalControl-EXE` и
  `TerminalControl-Installer` (установщик: ставит пульт в Program Files,
  создаёт ярлыки на рабочем столе и в меню "Пуск").

## Как пользоваться
1. Установи APK на телефон, открой — на экране код из 6 цифр.
2. Запусти пульт на ПК (или установи через TerminalControlSetup.exe).
3. Введи код -> "Подключить". Статус: подключено ✓.
4. Введи сумму -> "НАЧАТЬ ОПЛАТУ" — на телефоне откроется экран оплаты.
5. Покупатель выбирает: улыбкой (камера) или QR.
6. На пульте появится результат, звук подтвердит успех.

## Сеть
Телефон и ПК должны быть в одном Wi-Fi. Если "терминал не найден":
- проверь, что экран телефона включён;
- в роутере отключи изоляцию клиентов (AP isolation);
- разреши TerminalControl.exe в фаерволе Windows для частной сети.
