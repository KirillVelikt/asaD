# Юмани Терминал (демо)

Мобильное приложение-терминал (Android) + пульт управления с ПК.
Без реальной оплаты: демонстрационный режим, все платежи симулируются.

## Состав
- Android-приложение: заставка с музыкой, холостой экран с кодом подключения,
  экран оплаты (QR + NFC-эмуляция банковской карты), экран успеха/отказа со звуками
- Пульт для ПК (`pc-control/terminal_control.py`): подключение по 6-значному коду,
  ввод суммы, старт/отмена оплаты, приём статуса
- GitHub Actions: автосборка APK и EXE при пушe

## Протокол (TCP порт 8090)
```
CODE <6-значный код>   ->  OK / BAD
AMOUNT <сумма>         ->  OK        (на телефоне открывается экран оплаты)
STATUS                 ->  READY | SHOWING | PAID <RRN> | DECLINED
CANCEL                 ->  OK
BYE                    ->  OK
```
UDP-маяк: телефон шлёт каждые 2 сек `YUMANI_HERE|<код>` на порт 8091 —
пульт слушает его и находит IP терминала автоматически.

## Сборка APK
GitHub: вкладка Actions -> Build APK -> Artifacts -> app-debug-apk

## Сборка EXE пульта
GitHub: вкладка Actions -> Build EXE -> Artifacts -> TerminalControl-exe
Или локально: `pyinstaller --onefile --windowed --name TerminalControl terminal_control.py`

## Подключение
1. Запустите приложение на телефоне (код на экране)
2. Запустите пульт на ПК, введите код, нажмите «Подключиться»
3. Телефон и ПК должны быть в одном Wi-Fi
