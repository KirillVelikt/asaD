КАК СОБРАТЬ TerminalControl.exe (Windows)
==========================================

1. Установите Python 3.10+ с python.org (галочка "Add to PATH").
2. Откройте командную строку в папке pc-control и выполните:

   pip install pyinstaller
   pyinstaller --onefile --windowed --name TerminalControl terminal_control.py

3. Готовый ехешник появится здесь: pc-control/dist/TerminalControl.exe

Его можно копировать на любой Windows-компьютер — Python не нужен.

Альтернатива: EXE соберёт сам GitHub (workflow build-exe.yml) —
вкладка Actions -> Build EXE -> Artifacts -> TerminalControl.
